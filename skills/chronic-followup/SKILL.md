# 慢病随访自动化（高血压 / 糖尿病）

## 何时使用
- 需要在基本公卫系统批量补录/新增高血压或糖尿病随访记录；
- 名册里有较多「过期 / 快到期」患者，需逐人按规则录入后保存。

## 前置条件
1. 已用 `browser_*` 工具打开目标系统并保持登录（登录失效立即停止，不要重试）。
2. 取得浏览器 CDP 端口（浏览器以 `--remote-debugging-port=<port>` 启动）：
   ```powershell
   Get-CimInstance Win32_Process -Filter "Name='msedge.exe'" |
     Where-Object { $_.CommandLine -like '*<profile-dir>*' } |
     Select-Object -First 1 -ExpandProperty CommandLine
   ```
3. 设置环境变量（不要把院内地址写进仓库）：
   - `FOLLOWUP_BASE_URL`：系统根地址，如 `http://<内网地址>:<端口>`
   - `CDP_PORT`：上一步的端口

## 执行步骤
1. 先单人验证：
   ```bash
   node scripts/batch.mjs --disease hp --status 过期 --count 1 --flow scripts/flow-hypertension.js
   ```
2. 确认该患者已从名册「过期」列表消失，再放开批量：
   ```bash
   node scripts/worker.mjs --disease hp --status 过期 --max 200
   node scripts/worker.mjs --disease dm --status 过期 --max 200
   ```
3. 每批结束核对 `progress-*.jsonl` 中 `saved:true` 数量与名册变化一致。

## 硬性规则
- **日期**：到期日 = 上次随访 + 3 个月；实际日 = 到期日随机提前 0~20 天，不晚于 3 个月、不落在未来。
- **症状**：照抄上次。
- **血压**：110–139 / 71–89 随机整数，不能与上次完全相同。
- **心率**：60–89 随机，不能与上次相同（糖尿病表单无心率字段则跳过）。
- **引用医疗数据**：先取消「全选」；勾选体温/脉率/呼吸/空腹血糖/身高/体重/腰围（**血压不勾**）；用药只勾最近一次，提交后核对名称/剂型/规格/频率/用量/用法/依从性。
- **目标体重** = 原体重。
- **运动**（次/周,分钟/次 ×2）：
  - 高血压：≥80 岁 `3/30 5/30`；75–79 岁 `4/30 5/30`；其余保持原样。
  - 糖尿病：≥80 岁 `3/30 5/30`；75–79 岁 `4/30 5/30`；<65 岁 `5/30 5/30`；65–74 岁保持原样。
- **糖尿病**：足背动脉搏动统一「1触及正常」；主食(克/天) 统一 `240/240`。
- **保存前**：校验页头姓名与目标一致；用药行非空；缺项补齐后再保存。

## 失败处理
姓名不一致 / 登录失效 / 页面卡死 / 保存无「新增成功」→ **立即停止**并报告，不要盲目重试。
